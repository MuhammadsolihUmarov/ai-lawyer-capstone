# 2026-06-12 — Chat becomes a real product: rendering, composer, answer quality

This week's theme is turning the chat from "works" into "feels like a product".
Most of the day went into the surface the user actually touches.

## What I did

- **Markdown answers.** Assistant replies were rendered as `whitespace-pre-wrap`
  plain text, so the model's bold/headings/lists/tables showed as literal `**`
  and `##`. Wrote a small **dependency-free** Markdown renderer that returns
  React nodes (never `dangerouslySetInnerHTML`, so model output can't inject
  HTML) — headings, bold/italic, lists, code, blockquotes, links, simple tables.
- **Composer overhaul.** Single-line `<input>` → auto-growing `<textarea>` with
  **Enter-to-send / Shift+Enter** for a newline, a **Stop** button that aborts a
  streaming answer (AbortController), **Copy** and **Regenerate** on each
  assistant message, and **starter prompts** on the empty state.
- **Feedback that captures the "why".** 👍/👎 now opens an inline comment box
  ("what was helpful / what was wrong?") instead of silently posting a bare
  rating — the comment flows to the existing `/feedback` endpoint.
- **Answer quality.** The lawyer system prompt forbade all structure (max 3
  sentences, no headings/lists) and `LLM_MAX_TOKENS` was 400. Rewrote the prompt
  to "structured, concise, and ALWAYS complete" and raised the cap to 900 so a
  multi-part legal answer finishes instead of being chopped mid-sentence.
- **Knowledge-gap surface.** Added an "Areas to revisit" panel on the chat empty
  state (recurring legal topics + previously-unanswered questions from
  `GET /chat/insights`) so the gap-detection work is visible to the user.
- **Language → flags.** Replaced the language dropdown with an inline-SVG flag
  switcher across chat/analyze/draft.
- **Scannable landing.** Reworked the homepage into a clear top-to-bottom scan:
  value headline + a sample cited-answer card, a 3-step "how it works", light
  icon service cards (one line each), trust badges, closing CTA — and cut the
  uz+ru duplication that doubled every block's length.

## Problems encountered

- The brevity-capped prompt + 400-token ceiling truncated structured answers
  mid-sentence, and Claude ignored the "no structure" instruction anyway — so
  the rule was both wrong and unenforced.
- Flag **emojis** render as bare letter pairs ("UZ", "RU") on Windows.

## Solutions

- Aligned the prompt with what users actually want (structure when the question
  is multi-part, plain prose otherwise) and lifted the token cap; verified a
  ~70-word, fully-terminated, cited answer.
- Drew the flags as inline SVG so they render identically on every OS.
